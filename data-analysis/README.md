# Data analysis

Exploração, NLP e geração de métricas/insights a partir dos dados já processados.

- **Stack sugerida**: Jupyter, pandas, spaCy (extração de skills), scikit-learn, Metabase/Streamlit (visualização)
- **Responsabilidade**: limpeza analítica, extração de tecnologias das descrições, cálculo de métricas de mercado
- **Caso de uso relacionado**: UC03 (gerar análises e métricas de mercado) — ver `docs/escopo-e-casos-de-uso.md`
