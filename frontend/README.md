# Frontend

Dashboard do sistema de análise de vagas — visualização das métricas e listagem/filtro de vagas.

- **Stack**: React + Vite
- **Responsabilidade**: consumir a API (backend) e exibir gráficos e listagens de vagas
- **Construído em conjunto** pelos dois integrantes do projeto
- **Casos de uso relacionados**: UC04 (consultar dashboard) e UC05 (filtrar vagas) — ver `docs/escopo-e-casos-de-uso.md`

## Como rodar

```bash
cd frontend
npm install
npm run dev
```

Roda por padrão em `http://localhost:5173`.
